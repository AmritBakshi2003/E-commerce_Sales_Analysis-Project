# E-commerce Sales Analysis Project

Cleaned and analyzed 9k+ Wayfair orders to extract revenue insights. Built in Google Colab.

## Problem
Raw data had 24 messy categories, 38 duplicate orders, 199 missing prices, inconsistent dates.

## What I Did
- Standardized 24 categories → 8 clean categories
- Removed duplicates, fixed missing prices (category median)
- Monthly revenue trends & category performance
- Tools: Google Colab, Python, pandas, matplotlib

## Key Insights
- **Total Revenue:** $1.88M | **Profit:** $925K | **AOV:** $222
- **Top Category:** Furniture (~35%)
- **Peak:** Dec-Jan holiday season
- **Records:** 9245 → 9207 clean
